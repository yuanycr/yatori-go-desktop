# v0.4.2 发布说明

日期：2026-10-27（Asia/Shanghai）。

## 与已发布 v0.4.1 的区别

1. 上游 console 同步至 `b003030`；Go core 从 `cf6134fdb2bd` 更新到 `dca6f5d65861`，模块版本为 `v0.0.0-20261026155051-dca6f5d65861`。文档里的 core v2 与本应用版本号不是同一概念。
2. 账号默认开关统一为：章节测试开启、作业关闭、考试关闭。覆盖前端新建表单、后端配置归一化、worker 和学习通执行兜底；不改写已有显式开关。
3. 标准版全局并发账号数为 5。此前单独生成的 v0.4.1 max999 EXE 保留，不列入本次标准发布。
4. 核心元数据记录真实上游核心提交、模块版本与构建时桌面基线，另附 AAR/schema/元数据 SHA-256。现有产物的 `desktopCommit=6f3b9d0` 是提交本轮改动前的基线，不是完整发布源码 SHA；构建包含本次 v0.4.2 工作区改动，完整发布源码以两个仓库的 v0.4.2 tag 为准。
5. 桌面、Android、前端、mobilecore、构建脚本与文档统一为 v0.4.2，Android versionCode 为 42。发布工作流使用 go.mod 指定的 Go 版本。

## 随依赖引入的上游变更

对比本地保存的旧、新 core 模块源码，涉及共用 AI HTTP 请求、响应解析及重试组件，海旗科技作业/考试 API 与业务层，学习通人脸响应判定、登录、滑块及作业/考试流程，以及青书学堂、工学云等兼容调整。console 侧包含海旗科技作业/考试 AI 支持相关提交。这些是上游改动，不是本项目重新实现；各平台是否由本项目的定制 runner 调用相应路径、实际账号效果如何，仍需分别验证。

## 保留，不作为本次新增

- 账号独立定时停止、提交失败后刷新上下文并复用答案重试、滑块与考试码区分。
- Android 原有界面、日志面板布局、日志实时刷新及前台服务适配。
- Android 包含前次发布后已有的账号删除反馈修复。

## 已做检查与限制

- 此前 v0.4.1 候选包已在 Redmi K20 Pro / Android 11 安装至主用户，验证核心初始化、配置桥接、默认开关与上限 5；用户反馈手动基本测试无明显问题。
- 当前安全同步包的构建、校验结果见 [安全同步记录](security-sync-2026-10-27.md)，完整本地证据位于 release/security-sync-20261027；前序候选包记录位于 release/v0.4.2-verification。
- 学习通内置 AI 的 `45.113.20.54:443` 超时已定位；没有把外部接口超时宣称为已修复，也未针对该内置端点额外增加恢复逻辑。上游共用 AI 请求组件的调整不等于该内置服务已恢复。
- 未删除系统 PATH 仍使用的旧 Go。构建使用已安装的 Go 1.27.3，并未永久修改系统 PATH。
- 发布状态以两个仓库的 GitHub Release 页面为准；本地构建完成本身不代表已上传。
